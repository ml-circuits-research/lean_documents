[V02] A material scope amendment accepted on or after 2029-06-01 is governed by revision 2 only for the additional independently priced requirement introduced by that amendment. It does not erase competition obligations for the unchanged original requirement. A change is material when it adds a distinct functional requirement or increases unavoidable consideration; correcting a contact name or an internal billing code is not material. If an original and added requirement satisfy the aggregation rule, the buyer must document the aggregation analysis rather than presume that a new request number prevents it. The files for the two grandfathering examples state expressly that neither contains an added requirement, a price increase, or a genuine material amendment.
