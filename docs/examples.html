Evidence-to-Proof Review

Explore report checks in the local workspace

Start the dependency-free server from the repository root:

node tools/audit-ui.mjs

Open the audit workspace

Choose an example, inspect its documents, and open a report's verification run. Findings explain whether a claim is supported, contradicted, or cannot be established from the available evidence. The details dialog follows the recorded execution phases, with inputs, outputs, commands and actual check logs.

Start with a shopping receipt, a rental deposit, a parcel delivery or an electricity bill. Each has a careful report and a report with deliberate mistakes, checked separately.

There is no second copy of the run catalog in this documentation. New runs and their phase journals live under tmp/audit-runs/. Historical regression bundles remain under validation/runs/ and are not shown as fresh phase-recorded runs.
