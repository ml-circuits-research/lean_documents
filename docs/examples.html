Synthetic inputs • executed validation separate

Ten dossiers, twenty supplied reports

Each dossier contains synthetic source documents, a review brief, stable passage anchors, an input manifest, a deliberately flawed report, and a correct report. Each report is a separate audit input over the same sources.

“Correct” is an editorial target for a carefully scoped report, not a Lean certification. Correct reports can responsibly describe uncertainty, conflict, and subjective judgment. The flawed reports retain some correct findings so that an auditor must assess individual claims.

Input and evaluator separation

For one run, copy the brief, all sources, and the selected report into a fresh workspace. The other report is not additional evidence. Original excerpts needed by both variants must be in shared source documents. Fixture README files and evaluator annotations are packaging metadata, not source evidence.

The separate evaluator register records intended outcomes and explanations. Auditors always receive the report being checked; only the expected verdicts are withheld. The evaluator compares its expectations after the independent audit is complete and investigates disagreement rather than treating the key as infallible.

Two different validation stages

Preparation stage: editorial preparation and independent reading of the synthetic dossiers; verify manifests, anchors, claims, and internal consistency. Findings from this review are recorded in the fixture review record. That preparation record contains no executed Lean checks.

Approved implementation stage: run twenty isolated audits using the actual skill, compare claim outcomes with the evaluator register, reproduce any proofs, and assess explanation quality. Include both evidence-backed refutations and valuable insufficient-support results. Do not force every claim into a theorem.

Evaluation measures

  • False refutations on the correct reports; unsupported proof labels on either variant.
  • Detection of intentional errors and missing arguments, evaluated separately.
  • Evidence precision: correct anchors, speaker, negation, time, and version.
  • Argument quality: the exact failed premise or inference is visible and justified.
  • Abstention quality: unknown, conflicting, ambiguous, and nonformal cases retain appropriate limits.
  • Proof integrity: every published theorem reproduces under its recorded policy.
  • Coverage: every material claim has an outcome or explicit unresolved/excluded reason.

These ten dossiers are a seed set, not a statistical benchmark. Future expert review and additional adversarial cases are necessary before making reliability claims.
