# Synthetic spending record

[S1] The recorded amount for item A is 9 units.
[S2] An item is within budget exactly when its amount is at most 10 units.
[S3] This record contains no information about approval. Both approval states remain possible.

This fixture describes recorded values, not independently authenticated events.
Preserved execution artifacts. Text viewers work offline and over HTTP.
