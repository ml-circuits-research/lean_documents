[M02] For a P2 incident within the explicitly named maintenance operation, a qualifying detection occurring inside its authorized half-open window receives an effective acknowledgement-clock start at the window end. A detection outside the window receives no such deferral. The thirty-minute P2 acknowledgement allowance then runs from that effective start, inclusive at its deadline. This is a specific adjustment to an acknowledgement clock, not a declaration that the incident did not exist until the window ended. It does not change the accepted detection record, allow a missed acknowledgement before an already-ended window to be excused, or add time to a P1 containment limit. The incident and maintenance identifiers must match the authorized operation.
