# Audit brief

<a id="B01"></a>
## Finite scope
Audit one supplied report variant per run: VD-01 through VD-10 in `report.md`, or VD-C01 through VD-C09 in `report-correct.md`, only for cases D-201 through D-204, under fictional service workflow W-6. Evidence closes at 2028-03-20 18:00 UTC. Do not import real regulations, weekends, public holidays, or customary processing rules.

<a id="B02"></a>
## Calendar convention
Use Gregorian civil dates in UTC. A deadline expressed as N calendar days after a receipt date is computed by adding N dates, with the receipt date as day zero. The submission deadline is 17:00 UTC on the resulting date and is inclusive unless the applicable source expressly says otherwise. A 17:00 submission is timely; a 17:01 submission is late. The year 2028 has February 29. No next-business-day rollover exists for standard cases.

<a id="B03"></a>
## Sources and missing data
The amendment's explicit applicability rule controls version selection; dashboard labels are not authoritative policy rules. Every supplied receipt and submission timestamp is exact to the minute. The manifest lists a complete inventory of supplied files; it does not certify that missing rule annexes are empty or irrelevant. Annex R is explicitly absent and its contents must not be invented.

<a id="B04"></a>
## Assessment convention
Separate documentary support from formal execution: supported, refuted, both, and undetermined describe evidence-relative semantic states; qualitative language with no measurable criterion is nonformal. Unsupported precision about the missing annex is undetermined, not false by default. State prospective proof/refutation requirements without running Lean or claiming proof completion.

The selected supplied report is always visible to the auditor and is the object being audited. Creating a substantive report from the sources is outside this fixture. Evaluator-only expected outcomes remain separate and hidden during blind assessment. Neither supplied report is an authoritative evidence source for the other.
