# Model correspondence

The model uses P-17 revision 3 (P01). `Standard` implements P02: a supplied duty-manager approval exists and precedes start strictly. `Emergency` implements every P03 conjunct: qualifying incident, strict declaration ordering, and countersignature in the inclusive start-to-1440-minute interval. `Authorized` is their disjunction, exhaustive only because P01 expressly says so.

`Operation` records are transcriptions of R02–R05, in order c101 through c104. `approval`, `declaration`, and `countersignature` are timestamps for their explicitly named authorized officer roles, not arbitrary messages. `incident` records the active qualifying determination. `none` represents an explicit covered negative, relying on R01; it must never encode unknown C-105 evidence. An Operation record denotes the actual recorded start certified in R01. Thus the c104 witness is nonvacuous. There is no modeled C-105 record and no incompatible witness axioms.

Time origin is 2028-04-10 00:00 UTC. Integer minute offsets: R02 approval 520/start 540; R03 declaration 605/start 615/countersignature 2055; R04 approval and start 690; R05 start 800. The countersignature is on the next day, and 2055 - 615 = 1440. Gregorian minute differences were separately recomputed with Python datetime in time-transcription-check.json. No daylight-saving conversion is required because every source time is UTC. Strict inequalities and inclusive deadline follow brief B02 and P02/P03.

RecordKind only distinguishes the request category from the approval category under P02; the documentary identification of the 10:00 entry as a request comes from R03. The c02 theorem's none premise is a source transcription, not a self-authenticating observation. The theorem checks the resulting finite model.

Targets were written as explicit propositions before their proofs. c01 supports PA-C01's standard path and strict ordering. c02 supports PA-C02's covered absence and record-category distinction. c03 supports all PA-C03 timing and emergency conditions. c04 supports all PA-C04 negative path and prerequisite findings. c05 supports PA-C05's nonvacuous recorded start with both exhaustive paths failing. c08 supplies the concrete counterexample needed to support PA-C08's rejection of an invalid universal inference.

PA-C06, C07, C09, and C10 remain documentary assessments: no theorem purports to settle unknown external events, witness credibility, or prudence. Their supported epistemic claims must not be confused with proved underlying events. All six referenced theorems use core decidable propositions without custom axioms. Actual proof/target/axiom-check results are recorded by the helper, not inferred from this description.
