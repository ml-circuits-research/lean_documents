1# Fictional Policy P-17, approved revision 323<a id="P01"></a>4P-17 revision 3 governs all five operations C-101 through C-105 for the entire period covered by this dossier. There is no applicable superseding policy in this fixture. “Authorized start” means satisfying either the standard path P02 or the emergency path P03; these are the only two paths. An emergency path is fully established only when every P03 condition is met.56<a id="P02"></a>7The standard path requires an approval explicitly granted by the duty manager strictly before the operation starts. Submitting or acknowledging a request does not grant approval. Approval at the exact starting timestamp is not strictly before start.89<a id="P03"></a>10The emergency path requires all of: a qualifying active incident, a duty officer's emergency declaration strictly before start, and a duty manager's countersignature at or after start and no later than 24 hours after start. This path permits a start without a standard approval. The declaration alone does not complete this path.1112<a id="P04"></a>13P-17 prescribes no measure of whether a start was “prudent.” Authorization and prudence are separate assessments. The policy has no rule for resolving contradictory witness statements about an operation actually occurring.
