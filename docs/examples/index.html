Evidence audit example catalog

Explore 12 synthetic dossiers and 24 separately supplied report audits: the source documents, exact claims, intermediate decisions, Lean code, and actual saved proof logs. Each dossier pairs a deliberately mixed report with a cautious report intended to be correct.

The first ten dossiers retain legacy v1 audit bundles. Dossier 11 exercises v2 registration, inferred criteria, and separate audits of report arguments and conclusions without a separate brief. Dossier 12 tests an empty evidence file; it is coordinator-authored and audited, not blind, with independent post-review recorded separately. A proof passing does not certify source authenticity, extraction accuracy, or model adequacy.

Start with a dossier, choose one report variant, then follow its detailed findings to source snapshots and exact target logs. Missing arguments can be valuable support-gap findings without establishing that a conclusion is false.
