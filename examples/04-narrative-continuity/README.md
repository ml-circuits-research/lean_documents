# Does the story timeline make sense?

An editor reviews a fantasy story with a flashback and a revival. Compare the review with the story chronology and its stated world rules.

**Question:** Does the review place each scene and character correctly in time?

Upload the story chronology, a flashback, dialogue and world rules. Choose either [the careful report](report-correct.md) or [the report with deliberate errors](report.md) and audit it separately against all files in [sources/](sources/). Include `brief.md` for the supplied review conventions.

The audit can check event order, whether a character could attend a scene, and the difference between dialogue and established story facts. It reviews the supplied report, including its reasons and citations; it does not write the original report.

The documents do not resolve every character location or establish whether a scene is beautifully written.

These are fictional examples. Keep this guide, the alternate report, metadata, generation files and evaluator material outside the audit input. Evaluator expectations are withheld during a blind audit; the selected report and source documents are always available.

Historical execution records are indexed under [validation/runs](../../validation/runs/). This guide does not constitute a new validation run. Original reports and sources retain their bytes so they can be matched to prior results. New runs belong under `tmp/audit-runs/`, with a separate directory for each report.
