# Did the parcel arrive on time?

A customer compares a delivery summary with the promised arrival time and the signed receipt.

**Question:** Does the summary correctly describe delivery timing and the condition of the contents?

Upload either [the careful report](report-correct.md) or [the report with deliberate errors](report.md), together with [the source record](sources/record.md). Audit each variant separately. No separate brief is needed.

Check each report claim and its reasons against the stated amounts, dates and rules. The source also states what evidence is missing. A missing record does not prove that an event failed to occur.

This fictional example has three claims in each report. The auditor receives the selected report and source only; this guide and the alternate report are not evidence. No evaluator answer key is included.

These are newly prepared inputs, not a claim of completed validation. See [validation/runs](../../validation/runs/) for any subsequently retained execution records. New runs use separate directories under `tmp/audit-runs/` and must retain their actual proof logs.
