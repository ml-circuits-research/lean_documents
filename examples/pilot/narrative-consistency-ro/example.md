# Numele de pe ladă — povestire în cinci capitole

## Description

Două surori și un hamal se întâlnesc într-un depozit portuar. Un registru folosește două nume pentru aceeași persoană, iar o mărturie contestată ridică întrebări despre loc și intenție într-o povestire în cinci capitole.

## Review question
