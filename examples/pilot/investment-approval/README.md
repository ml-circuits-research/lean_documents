# Review an investment approval report

This is a demonstration dossier, not an actual investment file. This guide is not supplied to the auditor as source evidence.

The Investment Committee of Northbridge Growth Fund is considering a proposed equity investment in Cedar Components. The supplied report makes three statements about the transaction’s valuation, the approved allocation and compliance clearance.

Give the auditor `report.md` and the three documents in `sources/`: the proposed transaction terms, the approved committee decision and the compliance submission file. Each document carries case reference NB-CED-2026-11 and a date. The report and source sections have readable reference labels so the review can point to the exact statement and supporting text.

The task is to check the supplied report against those documents and explain the evidence and limits for each statement. It is not a request to originate an investment recommendation or perform external due diligence.

This pilot contains one report. This guide and `example.md` provide interface context and are not audit evidence. No audit findings or evaluator answer key are included.
