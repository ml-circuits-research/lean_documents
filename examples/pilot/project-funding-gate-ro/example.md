# Harbour House — deblocarea finanțării proiectului

## Description

Dosar demonstrativ pentru evaluarea instrumentului. O echipă de investiții private analizează contribuția de cofinanțare a sponsorului, etapele proiectului și autoritatea de eliberare a următoarei tranșe.

## Review question

Evidența contribuțiilor, condițiile privind etapele proiectului și limitele de autoritate susțin raportul de eliberare?
