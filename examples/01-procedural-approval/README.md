# Was the work approved?

A team starts work through normal approval or an emergency exception. Check whether a review correctly describes five recorded starts.

**Question:** Did each operation have the approval required when it started?

Upload approval rules, start times, an approval register and witness notes. Choose either [the careful report](report-correct.md) or [the report with deliberate errors](report.md) and audit it separately against all files in [sources/](sources/). Include `brief.md` for the supplied review conventions.

The audit can check approval timing, emergency conditions and the difference between requesting and receiving approval. It reviews the supplied report, including its reasons and citations; it does not write the original report.

The external handoff is incomplete and some witnesses disagree. Missing records do not establish that approval never happened.

These are fictional examples. Keep this guide, the alternate report, metadata, generation files and evaluator material outside the audit input. Evaluator expectations are withheld during a blind audit; the selected report and source documents are always available.

Historical execution records are indexed under [validation/runs](../../validation/runs/). This guide does not constitute a new validation run. Original reports and sources retain their bytes so they can be matched to prior results. New runs belong under `tmp/audit-runs/`, with a separate directory for each report.
